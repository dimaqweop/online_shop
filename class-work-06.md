# Домашнє завдання: Базове налаштування проєкту «Інтернет-магазин»

## Мета

- Навчитися розгортати фундамент для майбутнього інтернет-магазину.
- Створити та активувати віртуальне середовище.
- Встановити Django та створити перший проєкт.
- Ознайомитися зі структурою проєкту та додатків.
- Навчитися працювати з базовими міграціями та створювати суперкористувача.

---

## Кроки виконання

### 1. Підготовка середовища

1.  **Створіть робочу директорію** для вашого майбутнього магазину (наприклад, `online_shop`).
2.  **Створіть віртуальне середовище** у цій директорії:
    ```bash
    python -m venv venv
    ```
3.  **Активуйте віртуальне середовище**:
    - Windows: `venv\Scripts\activate`
    - Linux/macOS: `source venv/bin/activate`
4.  **Встановіть Django**:
    ```bash
    pip install django==5.2
    ```

### 2. Створення проєкту та додатку для магазину

1.  **Створіть новий проєкт** з назвою `my_shop`:
    ```bash
    django-admin startproject config .
    ```
    *(Примітка: крапка в кінці дозволяє створити файл manage.py у поточній директорії, що є стандартом для чистих проєктів)*
2.  **Створіть додаток** для основної логіки або товарів (наприклад, `main` або `catalog`):
    ```bash
    python manage.py startapp main
    ```
3.  **Зареєструйте додаток** у файлі `config/settings.py` у списку `INSTALLED_APPS`.

### 3. Налаштування бази даних та панелі керування

1.  **Застосуйте базові міграції** (це створить необхідні таблиці в БД для користувачів та сесій):
    ```bash
    python manage.py migrate
    ```
2.  **Створіть суперкористувача** (це буде ваш акаунт адміністратора магазину):
    ```bash
    python manage.py createsuperuser
    ```
    *(Введіть ім'я користувача, email та пароль)*

### 4. Перевірка результату

1.  **Запустіть сервер**:
    ```bash
    python manage.py runserver
    ```
2.  **Перевірте головну сторінку** за адресою `http://127.0.0.1:8000/`. Ви маєте побачити сторінку успішного встановлення Django.
3.  **Увійдіть в кабінет адміністратора** за адресою `http://127.0.0.1:8000/admin/`. Тут ви згодом зможете додавати товари та керувати замовленнями.

---

## Що здати на перевірку

1. Скріншот головної сторінки проєкту.
2. Скріншот успішного входу в адмін-панель.
3. Файл `requirements.txt` (створюється командою `pip freeze > requirements.txt`).
